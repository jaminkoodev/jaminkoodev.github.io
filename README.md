# Jamin Koo — portfolio site

Source for [jaminkoodev.github.io](https://jaminkoodev.github.io/). GitHub Pages builds this Jekyll site from the root of `master`.

- `index.html`: current portfolio landing page
- `writing.html`: archive of earlier posts
- `about.md`: background and contact
- `assets/site.css`: shared responsive styles
- `_posts/`: preserved writing and existing post URLs

The pull request workflow builds the site with GitHub's Jekyll Pages action. Changes to the live site are published by merging to `master`.
